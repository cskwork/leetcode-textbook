# LeetCode Textbook Learning Context

The textbook teaches beginners to recognize reusable algorithm patterns through an ordered, self-directed Java curriculum.

## Language

**Curriculum**:
The complete ordered learning path of 16 Patterns and 100 Problem Lessons.
_Avoid_: Library, catalogue

**Pattern**:
A reusable way of recognizing and solving a family of algorithm problems.
_Avoid_: Topic, category

**Problem Lesson**:
A route-identified teaching unit that guides a learner from intuition through a concrete dry-run. Its identity includes its Pattern because one LeetCode problem can appear in more than one Pattern.
_Avoid_: Problem page, LeetCode number

**Learning Station**:
One stage of the Problem Lesson flow: Intuition, Pseudocode, Java, Complexity, or Dry-run.
_Avoid_: Tab, section

**Checkpoint**:
A learner-controlled understanding check within a Problem Lesson. Revealing an answer does not prove mastery.
_Avoid_: Test, completion

**Lesson Status**:
The learner's explicit device-local state for a Problem Lesson: Not started, Studying, or Completed.
_Avoid_: Reading progress, mastery

**Interactive Walkthrough**:
An optional step-by-step visualization backed by a real visualization file for a specific Problem Lesson.
_Avoid_: Animation, demo

**Lesson Player**:
The guided presentation of a Problem Lesson that shows one Step at a time behind a progress bar. The Markdown stays the source of truth; the player only reveals it little by little.
_Avoid_: Wizard, slideshow

**Step**:
One bite-size segment of a Problem Lesson inside the Lesson Player. Every Learning Station is a Step; Warm-up, The problem, Traps, and Next up are Steps too.
_Avoid_: Slide, page

**Reading Mode**:
The learner's device-local choice between the step-by-step Lesson Player and the one-page scroll view. Both render the same Markdown.
_Avoid_: Layout, display setting

**XP**:
Device-local reward points for finishing Problem Lessons and first-time Checkpoint reveals. XP makes small sessions feel rewarding; it does not prove mastery.
_Avoid_: Score, grade

**Streak**:
The count of consecutive local days with learning activity. A streak survives until a full day is missed.
_Avoid_: Combo, chain
